# 1. 제품 개요 (Product Overview)

## 1.1 배경과 문제 정의

숏폼 콘텐츠(YouTube Shorts, Instagram Reels, TikTok)는 가장 소비량이 많은 영상 포맷이지만,
일반 사용자가 촬영한 원본 영상을 숏폼 규격으로 다듬는 일은 여전히 수작업이다.

- 가로(16:9)로 찍은 영상을 세로(9:16)로 변환하려면 피사체를 따라가며 크롭해야 한다.
- 하이라이트 구간을 골라 60초 이내로 줄이는 컷 편집이 필요하다.
- 자막, 배경음악, 인트로/아웃트로 등 숏폼 특유의 요소를 입혀야 조회수가 나온다.

**Shorts Editor**는 이 과정을 자동화한다. 사용자는 영상을 첨부하기만 하면,
시스템이 분석 → 편집 → 렌더링을 수행해 바로 업로드 가능한 숏폼 영상을 돌려준다.

## 1.2 제품 목표

| 구분 | 목표 |
|------|------|
| G1 | 영상 1개 첨부만으로 **개입 없이(Zero-touch)** 숏폼 완성본을 생성한다 |
| G2 | 자동 결과물을 사용자가 **가볍게 보정**(컷 조정, 자막 수정 등)할 수 있게 한다 |
| G3 | 주요 숏폼 플랫폼 3사(YouTube Shorts / Reels / TikTok) 규격을 **모두 만족**하는 출력을 보장한다 |
| G4 | 업로드부터 결과 수령까지 원본 길이 대비 **합리적 처리 시간**(목표: 원본 길이의 2배 이내)을 유지한다 |

## 1.3 타겟 사용자

| 페르소나 | 설명 | 핵심 니즈 |
|----------|------|-----------|
| 크리에이터 지망생 | 편집 도구를 다루지 못하는 일반인 | "찍은 걸 올리기만 하면 알아서 만들어줘" |
| 1인 크리에이터 | 롱폼을 운영하며 숏폼을 병행 | 롱폼 클립을 빠르게 숏폼으로 재가공 |
| 소상공인/마케터 | 제품·매장 홍보 영상 제작 | 템플릿 기반의 일관된 브랜딩 영상 |

## 1.4 범위 (Scope)

### 포함 (In Scope)
- 단일 영상 파일 업로드 → 숏폼 영상 자동 생성
- 장면/음성 분석 기반 하이라이트 추출 및 길이 조정
- 9:16 자동 리프레이밍(피사체 추적 크롭 또는 블러 배경 패딩)
- 음성 인식(STT) 기반 자동 자막 생성 및 스타일링
- BGM 삽입, 템플릿(인트로/아웃트로/스티커) 적용
- 생성 결과의 웹 미리보기와 경량 수동 보정(컷 범위, 자막 텍스트, 템플릿 교체)
- 최종 결과물 다운로드(MP4)

### 제외 (Out of Scope)
- 플랫폼 직접 업로드(YouTube/Instagram/TikTok API 연동) — 완성본 다운로드 후 수동 업로드로 충분
- 다중 영상 합치기(멀티 클립 프로젝트)
- 타임라인 기반 정밀 편집기(프로용 NLE 수준의 편집)
- 실시간 스트리밍 처리, 라이브 클리핑
- AI 영상 "생성"(text-to-video). 본 제품은 **기존 영상의 가공**만 다룬다

> 본 프로젝트는 비상업 오픈소스 프로젝트로, 위 제외 항목은 최종 확정이다
> ([로드맵 범위 결정](09-roadmap.md#m5--게시와-협업-v3--범위-제외) 참조).

## 1.5 용어 정의

| 용어 | 정의 |
|------|------|
| 원본(Source) | 사용자가 업로드한 영상 파일 |
| 잡(Job) | 원본 1개에 대한 1회의 숏폼 생성 요청 및 그 처리 단위 |
| 세그먼트(Segment) | 분석 단계에서 식별된 원본 내 연속 구간(장면, 발화 단위 등) |
| 하이라이트(Highlight) | 최종 출력에 포함하도록 선택된 세그먼트 집합 |
| 리프레이밍(Reframing) | 원본 화면비를 9:16으로 변환하는 작업(크롭/패딩) |
| 컴포지션(Composition) | 컷, 자막, BGM, 템플릿 등 최종 출력을 구성하는 편집 결정의 집합. 렌더링의 입력 |
| 프리셋(Preset) | 출력 스타일 묶음(자막 폰트/색, BGM 무드, 템플릿 등)의 사전 정의 |
| 렌더링(Rendering) | 컴포지션을 실제 영상 파일(MP4)로 인코딩하는 작업 |

## 1.6 출력 규격 기준 (플랫폼 요구사항 요약)

| 항목 | YouTube Shorts | Instagram Reels | TikTok | **본 제품 출력 기준** |
|------|----------------|-----------------|--------|----------------------|
| 화면비 | 9:16 권장 | 9:16 | 9:16 | **9:16 고정** |
| 해상도 | 1080×1920 권장 | 1080×1920 | 1080×1920 | **1080×1920** |
| 최대 길이 | 60초(180초까지 확대 중) | 90초 | 10분 | **기본 60초, 옵션 15/30/60/90초** |
| 컨테이너 | MP4 | MP4 | MP4 | **MP4 (H.264 + AAC)** |
| 프레임레이트 | ~60fps | ~60fps | ~60fps | **30fps 기본, 원본이 낮으면 원본 유지** |

> 세 플랫폼 교집합을 기본값으로 삼아, 하나의 출력물이 어디에든 업로드 가능하도록 한다.

## 1.7 성공 지표 (초기)

- 업로드 → 완성본 수령 성공률 ≥ 95% (지원 포맷 입력 기준)
- 자동 생성본을 **수정 없이 그대로 다운로드**하는 비율 ≥ 50%
- 처리 시간: 원본 60초 영상 기준 p50 ≤ 90초, p95 ≤ 3분
