# 8. 비기능 요구사항 (Non-Functional Requirements)

요구사항은 `NFR-#` 식별자로 관리한다.

## 8.1 입력 제한

| ID | 항목 | 값 |
|----|------|-----|
| NFR-1 | 최대 업로드 용량 | 2GB |
| NFR-2 | 원본 길이 | 3초 ~ 10분 |
| NFR-3 | 최대 입력 해상도 | 4K(3840×2160)까지 수용, 초과 시 거부 |
| NFR-4 | 세션당 동시 처리 잡 | 2개 (초과 시 429) |
| NFR-5 | 세션당 일일 잡 생성 | 20개 (초과 시 429) |

## 8.2 성능

| ID | 항목 | 목표 |
|----|------|------|
| NFR-10 | 처리 시간 (원본 60초, 1080p, CPU 기준) | p50 ≤ 90초, p95 ≤ 180초 |
| NFR-11 | 처리 시간 일반식 | 원본 길이의 2배 이내 (p95, 상한 10분 원본 기준) |
| NFR-12 | API 응답 (미디어 처리 외) | p95 ≤ 300ms |
| NFR-13 | 재렌더링 (분석 재사용) | 최초 생성 대비 ≤ 60% 시간 |
| NFR-14 | 상태 반영 지연 (워커 → 클라이언트) | ≤ 3초 |

## 8.3 신뢰성

| ID | 항목 | 내용 |
|----|------|------|
| NFR-20 | 잡 성공률 | 지원 포맷 입력 기준 ≥ 95% |
| NFR-21 | 워커 크래시 복구 | 처리 중 잡은 큐 재전달로 자동 재개 (단계 단위 재시작, 멱등 보장) |
| NFR-22 | 업로드 재개 | 청크 단위 재개, 미완료 세션 24시간 유지 |
| NFR-23 | 부분 실패 허용 | STT 실패 시 자막 없이 진행 등, 명세된 폴백 경로 준수 |

## 8.4 보안 / 프라이버시

| ID | 항목 | 내용 |
|----|------|------|
| NFR-30 | 업로드 파일 격리 | 사용자 파일은 세션 소유자 외 접근 불가. 다운로드는 서명 URL로만 |
| NFR-31 | 미디어 처리 격리 | ffmpeg/분석 워커는 네트워크 차단 샌드박스에서 실행 (악성 미디어 파일 대비) |
| NFR-32 | 입력 검증 | 컨테이너 파싱은 ffprobe 결과만 신뢰, 확장자·MIME은 참고용 |
| NFR-33 | 데이터 보존 | [7.5 보관 정책](07-data-model.md#75-보관삭제-정책) 준수, 사용자 삭제 요청 시 즉시 파일 삭제 |
| NFR-34 | 전송 암호화 | 전 구간 HTTPS/TLS |
| NFR-35 | 콘텐츠 책임 | 업로드 콘텐츠의 권리는 사용자 책임임을 약관에 명시. 자동 모더레이션은 v2 검토 |
| NFR-36 | BGM 라이선스 | 재배포 가능 라이선스 트랙만 라이브러리에 등록, 트랙별 license_note 필수 |

## 8.5 관측성 (Observability)

| ID | 항목 | 내용 |
|----|------|------|
| NFR-40 | 구조화 로그 | 모든 로그에 `jobId`, `stage`, `revision` 컨텍스트 포함 (JSON 로그) |
| NFR-41 | 메트릭 | 단계별 처리 시간, 큐 대기 시간, 실패율, 워커 가동률을 수집 (Prometheus 형식) |
| NFR-42 | 실패 분석 | FAILED 잡은 내부 오류 코드 + 스택 + 입력 메타데이터를 보존 (원본 파일은 정책대로 삭제) |
| NFR-43 | 품질 피드백 루프 | "수정 없이 다운로드" 비율, 자막 수정률(stt_corrections), 컷 보정률을 대시보드로 추적 |

## 8.6 호환성

| ID | 항목 | 내용 |
|----|------|------|
| NFR-50 | 브라우저 | 최신 Chrome/Safari/Edge/Firefox 2개 메이저 버전, 모바일 브라우저 포함 |
| NFR-51 | 출력 호환 | 출력 MP4는 YouTube Shorts/Reels/TikTok 업로드 요건을 모두 만족해야 한다 ([1.6](01-overview.md#16-출력-규격-기준-플랫폼-요구사항-요약)) |
| NFR-52 | 서버 환경 | linux/amd64 컨테이너, GPU 선택적(없어도 전 기능 동작) |
