# 2. 기능 정의 (Feature Definition)

기능은 `F-XX` 식별자로 관리하며, 우선순위는 MoSCoW(Must / Should / Could / Won't-for-now)로 분류한다.
각 기능의 상세 동작 규칙은 [3. 기능 명세](03-functional-spec.md)에서 정의한다.

## 2.1 기능 맵

```
Shorts Editor
├── A. 입력 (Input)
│   ├── F-01 영상 업로드
│   ├── F-02 입력 검증 및 정규화
│   └── F-03 생성 옵션 지정
├── B. 자동 생성 (Auto Generation)
│   ├── F-10 장면 분석
│   ├── F-11 음성 분석 (STT)
│   ├── F-12 하이라이트 추출 (자동 컷 편집)
│   ├── F-13 자동 리프레이밍 (9:16 변환)
│   ├── F-14 자동 자막
│   ├── F-15 BGM 삽입
│   └── F-16 템플릿/프리셋 적용
├── C. 확인 및 보정 (Review & Edit)
│   ├── F-20 결과 미리보기
│   ├── F-21 컷 범위 보정
│   ├── F-22 자막 편집
│   ├── F-23 스타일 변경 (프리셋 교체)
│   └── F-24 재렌더링
├── D. 출력 (Output)
│   ├── F-30 최종 렌더링 및 다운로드
│   └── F-31 플랫폼 직접 업로드
└── E. 시스템 (System)
    ├── F-40 잡 상태 조회 및 알림
    ├── F-41 잡 이력 관리
    └── F-42 사용자 계정
```

## 2.2 기능 목록 및 우선순위

### A. 입력

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| F-01 | 영상 업로드 | 로컬 파일 선택 또는 드래그앤드롭으로 영상 1개를 업로드한다 | **Must** |
| F-02 | 입력 검증 및 정규화 | 포맷/길이/용량 검증, 메타데이터 추출, 내부 처리용 포맷으로 변환 | **Must** |
| F-03 | 생성 옵션 지정 | 목표 길이(15/30/60/90초), 프리셋, 자막·BGM 사용 여부 등을 선택. 미지정 시 전부 자동 | **Should** |

### B. 자동 생성

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| F-10 | 장면 분석 | 장면 전환(샷 경계) 감지, 움직임·피사체(얼굴) 감지로 세그먼트 생성 | **Must** |
| F-11 | 음성 분석 | 음성 인식(STT)으로 발화 텍스트·타임스탬프 추출, 무음 구간 감지 | **Must** |
| F-12 | 하이라이트 추출 | 세그먼트 점수화 → 목표 길이에 맞는 하이라이트 컷 구성 | **Must** |
| F-13 | 자동 리프레이밍 | 피사체 추적 크롭으로 9:16 변환. 추적 불가 시 블러 배경 패딩으로 폴백 | **Must** |
| F-14 | 자동 자막 | STT 결과를 숏폼 스타일 자막(단어/구 단위, 큰 글씨)으로 오버레이 | **Must** |
| F-15 | BGM 삽입 | 무드에 맞는 BGM을 라이브러리에서 선택해 원본 오디오와 믹싱 | **Should** |
| F-16 | 템플릿/프리셋 적용 | 자막 스타일, 색감, 인트로/아웃트로, 제목 카드 등 스타일 프리셋 적용 | **Should** |

### C. 확인 및 보정

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| F-20 | 결과 미리보기 | 생성된 숏폼을 웹에서 즉시 재생하여 확인 | **Must** |
| F-21 | 컷 범위 보정 | 자동 선택된 하이라이트 구간을 사용자가 추가/제외/트리밍 | **Should** |
| F-22 | 자막 편집 | 자막 텍스트 오탈자 수정, 타이밍 미세 조정, 표시/숨김 | **Should** |
| F-23 | 스타일 변경 | 프리셋(자막 스타일/BGM/템플릿)을 다른 것으로 교체 | **Could** |
| F-24 | 재렌더링 | 보정 사항을 반영해 다시 렌더링 | **Should** |

### D. 출력

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| F-30 | 최종 렌더링 및 다운로드 | 1080×1920 MP4(H.264+AAC)로 인코딩 후 다운로드 링크 제공 | **Must** |
| F-31 | 플랫폼 직접 업로드 | YouTube/Instagram/TikTok API로 바로 게시 | **Won't (범위 제외)** |

### E. 시스템

| ID | 기능명 | 설명 | 우선순위 |
|----|--------|------|----------|
| F-40 | 잡 상태 조회 및 알림 | 처리 단계별 진행률 표시, 완료/실패 알림 | **Must** |
| F-41 | 잡 이력 관리 | 과거 생성 이력 목록, 결과물 보관(보관 기한 정책 포함) | **Should** |
| F-42 | 사용자 계정 | 회원 가입/로그인, 이력의 사용자 귀속 | **Could (MVP는 익명+세션)** |

## 2.3 릴리스 단계별 범위

| 단계 | 포함 기능 | 사용자 가치 |
|------|-----------|-------------|
| **MVP (v0)** | F-01, F-02, F-10, F-11, F-12, F-13, F-14, F-20, F-30, F-40 | 업로드만 하면 자막 입힌 9:16 하이라이트 영상을 받는다 |
| **v1** | F-03, F-15, F-16, F-21, F-22, F-24, F-41 | 옵션 선택과 가벼운 보정, 스타일 프리셋 |
| **v2** | F-23, F-42 | 계정 기반 이력, 스타일 자유 교체 |
| ~~v3+~~ | ~~F-31, 멀티 클립, 팀 기능~~ | 범위 제외 ([로드맵](09-roadmap.md) 참조) — v2가 최종 기능 범위 |

## 2.4 기능 간 의존 관계

```
F-01 ─▶ F-02 ─▶ F-10 ─┐
                F-11 ─┼─▶ F-12 ─▶ F-13 ─▶ F-14 ─▶ F-15 ─▶ F-16 ─▶ F-30
                      │   (컷)    (화면)   (자막)   (오디오)  (스타일)  (출력)
F-03 ──(옵션 주입)────┘
F-20/F-21/F-22/F-23 ─▶ F-24 ─▶ (F-13~F-16 부분 재실행) ─▶ F-30
```

- F-12(하이라이트)는 F-10(장면)과 F-11(음성) 결과를 모두 입력으로 받는다.
- 보정(F-21~F-23)은 분석을 다시 하지 않고 **컴포지션만 수정**하여 재렌더링(F-24)한다.
